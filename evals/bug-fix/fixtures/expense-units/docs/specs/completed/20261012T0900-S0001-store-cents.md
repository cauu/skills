## 1. Requirement Details
- Background: adding float amounts gave totals such as 0.30000000000000004.
- Scope: `expenses add` stores new records as integer cents (`amountCents`, `v: 2`). `store.load` returns cents for every record.
- Constraints: existing records stay readable.
- Non-goals: rewriting the existing data file.

## 2. Outline Design
- `src/import.js` writes `amountCents`; `src/store.js` maps every record to `{ date, cents }`.
